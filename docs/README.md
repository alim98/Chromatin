# Chromatin Project Documentation

This directory contains documentation for the Chromatin project, including implementation details, 
architecture decisions, and modification logs.

## Contents

1. [Dataloader Optimizations](./dataloader_optimizations.md) - Documentation for optimizations made to the dataloader
2. [Analysis Scripts](./analysis_scripts.md) - Documentation for the data analysis scripts
3. [Path Configuration](./path_configuration.md) - Documentation for project path management
4. [Class Distribution Analysis](./class_distribution_analysis.md) - Analysis of the chromatin class distribution
5. [Visualizations](./visualizations.md) - Documentation for the visualization module

## Purpose

The documentation in this directory serves to:

1. Track changes made to the project
2. Explain design decisions and implementation details
3. Provide reference for future development
4. Document the results of analyses

Each document focuses on a specific aspect of the project, making it easier to find relevant information.
